# Prank Camera Bot (بموافقة واضحة)

## الملفات
- `app.py`: بوت تيليجرام + صفحة ويب.
- `requirements.txt`: المكتبات المطلوبة.

## 1) إنشاء البوت
1. افتح تيليجرام وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع الخطوات.
3. انسخ Token واحفظه سراً. لا ترسله لأي شخص.

## 2) رفع المشروع
1. أنشئ مستودع GitHub جديداً وارفع `app.py` و`requirements.txt`.
2. في Render أنشئ **Web Service** واربطه بالمستودع.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app`
5. أضف Environment Variables:
   - `BOT_TOKEN` = رمز البوت من BotFather
   - `PUBLIC_URL` = رابط Render الذي سيظهر لك، مثل `https://your-app.onrender.com`
   - `OWNER_CHAT_ID` = اتركه فارغاً مؤقتاً في البداية (أو أضفه بعد الخطوة التالية).

## 3) معرفة Chat ID
بعد تشغيل الخدمة:
1. افتح البوت واضغط Start أو أرسل `/start`.
2. أرسل `/myid` وخذ الرقم الذي يظهر لك.
3. في Render أضف `OWNER_CHAT_ID` بهذا الرقم ثم أعد تشغيل الخدمة.

## 4) الاستخدام
- أرسل `/link` للبوت ليعطيك رابط صفحة المقلب.
- شارك الرابط مع صديقك.
- الصفحة تطلب إذن الكاميرا بوضوح. لا تُرسل الصورة إلا بعد أن يضغط المستخدم زر «التقاط وإرسال الصورة» ويؤكد الإرسال.

## ملاحظات مهمة
- الكاميرا تعمل فقط على HTTPS أو localhost، لذلك استخدم رابط Render الآمن.
- لا يمكن ولا ينبغي تشغيل الكاميرا سراً أو تجاوز إذن المتصفح.
- لا تنشر Token في GitHub أو في المحادثات. إذا انكشف، ألغِه من BotFather وأنشئ Token جديداً.
- أخبر أصدقاءك بوضوح أن الصورة ستُرسل إليك، واحصل على موافقتهم.
